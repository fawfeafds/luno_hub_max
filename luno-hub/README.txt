LUNO HUB: вхід по коду з листа + два сайти

ВАЖЛИВО: перетягування папки у Netlify Drop НЕ запускає функції (send-code і verify-code).
Потрібен деплой через GitHub або через Netlify CLI.

1) Пошта. Зареєструйся на resend.com, створи API-ключ.
   Без своєї верифікованої домени Resend шле листи тільки на твою власну пошту (для тесту).
   Щоб слати всім, додай домену в Resend і вкажи MAIL_FROM, наприклад: Luno <login@твійдомен.com>

2) Netlify. Створи новий сайт з цієї папки:
   Варіант А (GitHub): завантаж папку в репозиторій, у Netlify: Add new site, Import from Git.
   Варіант Б (термінал): у цій папці виконай  npx netlify-cli deploy --prod

3) У Netlify: Site configuration, Environment variables, додай три змінні:
   RESEND_API_KEY   твій ключ з Resend
   SESSION_SECRET   довгий випадковий рядок (30+ символів)
   MAIL_FROM        від кого слати (необов'язково для тесту)
   Після цього зроби повторний деплой.

Код діє 10 хвилин, 5 спроб, повторна відправка раз на хвилину. Сесія 30 днів.
